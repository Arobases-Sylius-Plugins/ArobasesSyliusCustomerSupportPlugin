# UPGRADE FROM `1.x` TO `2.0`

The `2.x` version of the plugin requires **Sylius 2.3** (Symfony 6.4/7.4, Doctrine ORM 3 / DBAL 4, PHP 8.2+).

## 1. Update the dependencies

```bash
composer require sylius/sylius:^2.3 arobases-sylius-public/sylius-customer-support-plugin:^2.3
```

## 2. Configuration

Keep importing `@ArobasesSyliusCustomerSupportPlugin/Resources/config/resources.yaml`: it now also imports the
Twig hooks configuration. The `config.yaml` file (Sylius 1 template events) has been removed.

## 3. Routing

The admin routes are now generated by the `sylius.resource` loader. Route **names** are unchanged
(`arobases_sylius_customer_support_plugin_admin_customer_support_*`), only the URLs changed
(`/customer-support/{id}/update` → `/customer-support/{id}/edit`, `DELETE /customer-support/{id}/delete` → `DELETE /customer-support/{id}`).

Import them under the admin path:

```yaml
# config/routes/arobases_sylius_customer_support_plugin.yaml
arobases_sylius_customer_support_plugin_admin:
    resource: "@ArobasesSyliusCustomerSupportPlugin/Resources/config/admin_routing.yml"
    prefix: '/%sylius_admin.path_name%'

arobases_customer_support_plugin:
    resource: "@ArobasesSyliusCustomerSupportPlugin/Resources/config/shop_routing.yml"
```

The shop routes (names and URLs) are unchanged.

## 4. Templates

All the templates have been rewritten for the Sylius 2 admin (Tabler) and shop (Bootstrap) and moved:

| 1.x                                                       | 2.x                                                                           |
|-----------------------------------------------------------|-------------------------------------------------------------------------------|
| `Admin/Crud/update.html.twig`, `Admin/form.html.twig`...   | `@SyliusAdmin/shared/crud` + hooks `arobases_sylius_customer_support_plugin.admin.customer_support.*` |
| `Shop/Account/CustomerSupport/*.html.twig`                | `shop/account/customer_support/*.html.twig` + hooks `arobases_sylius_customer_support_plugin.shop.account.customer_support.*` |
| `Email/customer_support_answer_notification.html.twig`    | `email/customer_support_answer_notification.html.twig`                        |

Remove your overrides of the 1.x templates (`templates/bundles/ArobasesSyliusCustomerSupportPlugin/...`) and customize the
pages through the Twig hooks instead (`bin/console sylius:debug:twig-hooks`).

## 5. Code changes

* Entities are mapped with Doctrine attributes, the mapping is declared by the plugin.
  `CustomerSupport::$customer` / `$order` now target `CustomerInterface` / `OrderInterface` (resolved to your entities).
* `Menu\AccountMenuBuilder` (decoration of the shop account menu) has been replaced by the `Menu\AccountMenuListener`
  listener on the `sylius.menu.shop.account` event.
* `ChangeStatusCustomerSupportController` now checks the CSRF token (`_csrf_token`, token id = ticket id) and,
  in the shop, only allows a customer to open/close **his own** tickets.
* `CustomerSupportListener` depends on `SendNotificationAnswerEmailManagerInterface` (aliased service), so the e-mail
  manager can be decorated.
* The answer message is a textarea in the admin.

## 6. Database

No change: the `arobases_customer_support` and `arobases_customer_support_answer` tables are identical in 1.x and 2.x.
